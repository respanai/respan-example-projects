# Replicate Python tracing examples

These examples use the released Replicate SDK and actual HTTP/SSE parsers against controlled local HTTPX transports. They run without a Replicate key or provider calls and were checked with SDK 1.0.7 and minimum 1.0.0.

```bash
python -m pip install -r requirements.txt
python run_all.py
```

Install the companion instrumentor branch or built wheel while reviewing this unreleased update. The released package requirement alone does not include the fixes in the companion PR.

| Script | Coverage |
| --- | --- |
| `01_generation.py` | Native generation, zero/false/empty options |
| `02_streaming.py` | 251 native SSE events, lazy start, partial close, no-read close |
| `03_async.py` | Async generation/streams, prediction lifecycle, model/deployment routes |
| `04_prediction_lifecycle.py` | Polling, get/list/cancel, native model/deployment prediction creation |
| `05_provider_errors.py` | Actual SDK API 429 and model failure exceptions |
| `06_full_payloads.py` | 5,001-component vector, 75-message history, tool schema, credential redaction |
| `07_file_output.py` | Native `FileOutput` reads and async reads |
| `08_privacy.py` | Content opt-out and irreversible late stream veto |
| `09_pending_lifecycle.py` | Independent pending streams and bodyless abandonment |

`use_file_output=True` is explicit because native defaults differ between the tested SDK versions. Streaming uses a protocol proxy, preserving laziness and yielded event identity; the generator's concrete type and identity differ. Call `close()` or `aclose()` for deterministic resource cleanup.

For explicit Respan export, set `RESPAN_EXAMPLE_EXPORT=1`, `RESPAN_API_KEY`, and optionally `RESPAN_BASE_URL` (defaults to `https://api.respan.ai/api`). All exported data is generated by these controlled fixtures. `RESPAN_EXAMPLE_RUN_ID` sets an exact marker shared by the run. `RESPAN_EXAMPLE_REPORT_DIR` writes local span reports; `RESPAN_EXAMPLE_WIRE_DIR` records actual exporter HTTP payloads and status codes. Wire reports contain controlled bodies and should be kept outside the repository.

Local assertions, successful HTTP export, and semantic acceptance of stored traces are separate checks. Stored trace inspection must verify the exact marker's trees, attributes, full input/output, error status, vectors, and privacy behavior.
